# TouchpadBlocker

WindowsノートPCのタッチパッド誤操作によって発生する、ゲームへの意図しない `Ctrl` 入力を抑制するための小さな常駐ツールです。

## 背景

一部のノートPCには、タッチパッドの端や隅にタッチパッドのON/OFFを切り替える領域があります。

この領域に手が触れると、タッチパッドのON/OFFと同時に特殊なキーボード入力が発生する機種があります。

このツールを作成した環境では、タッチパッドのON/OFF操作に伴って、

```text
LWin + LCtrl + F24
```

という入力が発生していました。

ゲーム側ではこの入力の一部が通常の `Ctrl` として認識され、ゲーム中に意図せず操作が発生する問題がありました。

TouchpadBlockerは、この特殊な入力だけを検出してゲーム側へ渡さないようにします。

## 特徴

- 通常の `Ctrl` キーは使用可能
- `LWin` キーをブロックしない
- `LWin + LCtrl + F24` の特殊入力のみ抑制
- タッチパッド自体を無効化する必要がない
- 外部ライブラリ不要
- .NET SDKやVisual Studioをインストールせず、既存のWindows付属C#コンパイラでビルド可能

## 動作

通常の `Ctrl` 入力は短時間保留されます。

```text
LCtrl ↓
  ↓
特殊入力が発生しない
  ↓
通常のCtrlとして処理
```

タッチパッド由来の入力の場合は、

```text
LWin ↓
LCtrl ↓
F24 ↓
```

を検出し、`Ctrl` および `F24` をアプリケーション側へ渡しません。

`LWin` 自体はそのまま通します。

## 必要環境

- Windows
- `csc.exe` が利用可能な環境
- 管理者権限

このリポジトリでは.NET SDKやVisual Studioのプロジェクトは使用していません。

Windowsに標準搭載されている.NET Framework 4.x系のC#コンパイラを使用します。

## ビルド

リポジトリを取得したら、`build.bat` を実行してください。

```text
build.bat
```

成功すると、

```text
TouchpadBlocker.exe
```

が生成されます。

## 実行

`run.bat` を実行するか、`TouchpadBlocker.exe` を直接起動してください。

ゲームなどの管理者権限で動作するアプリケーションからの入力を確実に抑制するため、**TouchpadBlockerも管理者権限で実行することを推奨します。**

Windowsではショートカットの設定で管理者権限で起動するチェックボックスがあるため、run.batを管理者権限で実行する.lnkを作成するのが一番楽です。

## 注意

このツールはタッチパッドそのものを無効化するものではありません。

そのため、タッチパッドのON/OFF状態が切り替わった際に、PCやタッチパッドドライバによっては画面上にON/OFF通知が表示される場合があります。

この通知自体はTouchpadBlockerでは制御していません。

また、このツールは特定の機種で発生する入力パターンを対象としているため、すべてのタッチパッドで動作することを保証するものではありません。

また、Ctrlの発火が100ms遅延します。
